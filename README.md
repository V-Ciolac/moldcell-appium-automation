# Автоматизация тестирования Moldcell (Appium + WebdriverIO)

Проект содержит автоматизированные UI-тесты для Android-приложения (доступная без авторизации часть).
Тесты написаны с использованием паттерна Page Object Model (POM) на JavaScript (ESM).

## Предварительные требования (Pre-conditions)
1. Установлен Node.js (v16+).
2. Установлен Java JDK (v17+) и Android Studio.
3. Настроены переменные окружения `ANDROID_HOME` и `JAVA_HOME`.
4. Запущен эмулятор Android (API 33/34).
5. На эмулятор установлено тестируемое приложение (md.moldcell.selfservice).

## Установка зависимостей
Перед первым запуском необходимо установить все зависимости проекта:
\`\`\`bash
npm install
\`\`\`
## Настройка переменных окружения
В целях безопасности чувствительные и тестовые данные (номера телефонов, тексты ошибок) не хранятся в репозитории. 
Перед запуском тестов создайте файл `.env` в корне проекта и добавьте в него  нужные переменные

## Запуск тестов
Для запуска тестов одной командой используйте:
\`\`\`bash
npm run wdio
\`\`\`

## Структура проекта
* `test/specs/` — сценарии тестов (позитивный и негативный).
* `test/pageobjects/` — классы экранов (Page Objects) с методами взаимодействия.
* `test/locators/` — централизованное хранилище локаторов (XPath, ID).
* `test/data/` — тестовые данные (номера телефонов, тексты ошибок).

## Обработка ошибок
В проекте настроены явные ожидания (`waitForDisplayed`, `waitForClickable`). 
В случае падения теста (например, если элемент не найден):
1. В консоль выводится понятное сообщение об ошибке (Assertion Message).
2. Автоматически создается скриншот экрана устройства в момент падения (через хук `afterTest`).
